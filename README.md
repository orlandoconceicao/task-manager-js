# Gerenciador de Tarefas

Aplicação web de estudo para controlar tarefas diretamente no navegador, com busca, filtros e persistência local.

## Funcionalidades

- criação, edição e exclusão de tarefas;
- marcação de tarefas concluídas;
- pesquisa em tempo real;
- filtros por status;
- persistência com LocalStorage.

## Tecnologias

HTML5, CSS3, JavaScript, DOM, LocalStorage e Font Awesome.

## Execução

Abra o arquivo `index.html` no navegador. As tarefas ficam armazenadas localmente.
